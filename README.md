# Levoit ESPHome

A Home Assistant integration for air purifiers and humidifiers running the
[`levoit`](https://github.com/tuct/levoit) or `philips` ESPHome components.

It finds every device built with those components, links it to its config in
the ESPHome Device Builder, and offers an update when a newer component version
is published, compiled and uploaded through the Device Builder.

Work in progress — see the
[plan](https://github.com/tuct/levoit/blob/main/docs/firmware-updates.md).
